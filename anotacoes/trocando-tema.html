📄 Documentação: Alternância de Tema (Dark/Light)

🧩 Visão Geral

Este código implementa um botão de alternância de tema entre Dark Mode e Light Mode em uma página web. A troca é feita dinamicamente com JavaScript e os estilos são definidos via CSS utilizando variáveis customizadas (CSS Variables). O estado do tema é persistido no localStorage.

🎛️ HTML: Botão de Troca de Tema

<button id="btn-trocar-tema" title="Trocar tema">
  <svg class="icone-sol">...</svg>
  <svg class="icone-lua">...</svg>
</button>
  • id="btn-trocar-tema": Identificador único para aplicar lógica de clique.
  • title="Trocar tema": Dica visual ao passar o mouse.
  • icone-sol e icone-lua: Ícones SVG que representam os temas. Apenas um é exibido por vez, dependendo do tema ativo.

🎨 CSS: Estilização e Temas

🌑 Tema Dark (padrão)

Definido em :root, com variáveis como:

  • --bg-primario: Cor de fundo principal.
  • --texto-primario: Cor do texto principal.
  • --font-base: Fonte padrão.
  • font-size: Usa clamp() para responsividade.

☀️ Tema Light

Ativado com o atributo data-theme="light" no <body>. Sobrescreve as variáveis do tema escuro.

[data-theme="light"] {
  --bg-primario: #F5F5F5;
  --texto-primario: #212121;
  ...
}

🔁 Alternância de Ícones

.icone-lua { display: none; }
.icone-sol { display: block; }

[data-theme="light"] .icone-lua { display: block; }
[data-theme="light"] .icone-sol { display: none; }

🧠 JavaScript: Lógica de Alternância

const salvarTema = localStorage.getItem('tema');
if (salvarTema === 'light') {
  document.body.setAttribute('data-theme', 'light');
}
  • Verifica se o usuário já escolheu o tema anteriormente.
  • Se sim, aplica o tema salvo ao carregar a página.

📌 Evento de Clique

btnTrocarTema.addEventListener('click', function () {
  if (document.body.hasAttribute('data-theme')) {
    document.body.removeAttribute('data-theme');
    localStorage.setItem('tema', 'dark');
  } else {
    document.body.setAttribute('data-theme', 'light');
    localStorage.setItem('tema', 'light');
  }
});
  • Alterna entre os temas ao clicar no botão.
  • Atualiza o localStorage para manter a preferência do usuário.
